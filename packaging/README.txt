================================================================
  zzqAI  v1.2.0  ——  Quake 3 机器人 AI 增强模组
================================================================

一个"解压即用"的独立模组：不需要启动参数，不需要控制台命令。


----------------------------------------------------------------
一、安装（三步，都是鼠标操作）
----------------------------------------------------------------

1. 把压缩包里的  zzqai  这个文件夹，整个拖进 Quake 3 的安装根目录，
   和 baseq3 文件夹放在同一层。

   装完应该是这样：

        <Quake3>/baseq3/
        <Quake3>/zzqai/
        <Quake3>/zzqai/zzqai.pk3
        <Quake3>/zzqai/description.txt
        <Quake3>/zzqai/README.txt       ← 本文件

   注意：是放到 baseq3 的"旁边"，不是放进 baseq3 里面。

2. 启动游戏，进主菜单的  MODS（模组）菜单，
   列表里会多出一项  zzqai ，选中它。

3. 回到主菜单，进  MULTIPLAYER → CREATE ，
   选一张地图、选个模式（FFA 最省事），开始游戏。

   —— 这时场上只有你自己，机器人由你在菜单里手动添加（见下一节）。


----------------------------------------------------------------
二、加机器人和选难度（重点）
----------------------------------------------------------------

进游戏后，按  ESC  打开菜单，选  ADD BOTS ：

    ┌─────────────────────────────────────┐
    │  BOT SKILL        < I Can Win >     │  ← 难度，左右键切换
    │                                     │
    │  [ ] Anarki                         │
    │  [ ] Bitterman                      │  ← 勾选想加的机器人
    │  [ ] Crash                          │      （可多选，也可以一个人不加）
    │  [ ] ...                            │
    │  [ ] zzqBOT                         │  ← 本模组的招牌机器人
    │                                     │
    │          [  FIGHT  ]                │  ← 开始
    └─────────────────────────────────────┘

    · BOT SKILL 五档对应内部技能值 1–5：
         I Can Win      1    最弱
         Bring It On    2
         Hurt Me Plenty 3
         Hardcore       4
         Nightmare      5    最强

    · 你也可以直接选不同难度分别加几个，凑成一支强弱混合的队伍。

    · 加完之后想再补人，再进一次 ADD BOTS 就行；
      想踢人，在游戏里按 ~ 打开控制台输入  kick <名字> 。


----------------------------------------------------------------
三、这个模组到底改了什么
----------------------------------------------------------------

机器人本身还是 brainworks 的 AI，但比原版多出六个模块，
在"菜单里加机器人"这件事上完全不用你操心 —— 它们是内置的：

    M1 对手档案    它会记住你惯用什么武器、爱走哪条路
    M2 物品时钟    它会算护甲/血包的重生时间，提前去卡位
    M3 残血脱离    它血量低于 40 时会边打边撤，去补血，不再送命
    M4 连击闪避    被打中后它会横移躲子弹，不会傻站着
    M5 自适应难度  它按战况自动升降自己的技术水平
    M6 团队情报    团队模式下它会和队友分享"在哪看见过敌人"

这六项默认全部开启，不需要你做任何事。


----------------------------------------------------------------
四、想调怎么办（可选，不影响正常玩）
----------------------------------------------------------------

A. 用控制台精确加机器人 —— 游戏里按 ~ 呼出控制台：

       addbot                       加一个随机机器人
       addbot zzqBOT 5              加 zzqBOT，技能 5（最凶）
       addbot Anarki 1              加 Anarki，技能 1（最弱）

   格式：  addbot <名字> [技能 1-5] [队伍] [延迟毫秒] [显示名]

B. 让它自动补人 —— 如果你懒得每次手动加：

       bot_minplayers 3             场上始终保持 3 人

   设 0 就是关掉（默认就是 0）。

C. 那六个模块属于"作弊类"变量，在控制台里要先解锁才能改：

       sv_cheats 1                  解锁
       bot_profile 0                关掉 M1 对手档案
       bot_item_wait 0              关掉 M2 物品时钟
       bot_duel 0                   关掉 M3 残血脱离
       bot_duel_move 0              关掉 M4 连击闪避
       bot_adaptive 0               关掉 M5 自适应难度
       bot_share 0                  关掉 M6 团队情报共享

   改回 1 就是重新打开。全部设 0 时，机器人行为与
   未经改造的 brainworks 原版完全一致。

D. 想看它的判断过程 —— 打开诊断日志：

       sv_cheats 1
       bot_adaptive_report 1        打印自适应难度的调整记录
       bot_share_report 1           打印团队情报的收发记录
       bot_duel_debug 1             打印残血脱离的触发

   这些输出会写进 qconsole.log，方便排查。


----------------------------------------------------------------
五、卸载
----------------------------------------------------------------

把 <Quake3>/zzqai 整个文件夹删掉即可。
游戏的其他部分一个字节都没动 —— 本模组只存在于这个文件夹里。


----------------------------------------------------------------
六、如果它没出现在 MODS 菜单里
----------------------------------------------------------------

* 检查路径：必须是 <Quake3>/zzqai/zzqai.pk3，
  不能是 <Quake3>/zzqai/zzqai/zzqai.pk3（多套了一层）。
* 检查大小写：文件夹名要正好是 zzqai。
* 检查游戏目录：zzqai 要和 baseq3 在同一层。

如果 ADD BOTS 菜单里一个机器人都没有，在控制台看一眼：

       bot_enable                   应该是 1

手动补一个：  addbot
