# 机器人智力对照：所有 bot 一样聪明吗？

> 结论先说：**算法同一份，差别只在参数。** 同一档位下 zzqBOT 的参数确实比原版 bot 更强，
> 但 zzqAI 的 M5 自适应难度（默认开）会主动把差距拉平。
>
> 本文数据来源：`Z:/q3brainworks/code/game`（源码直读）+ `baseq3/pak0.pk3`（原版角色文件）
> + quake3e 专用服务器实跑日志。

---

## 一、AI 算法只有一份，没有"特招生"

每个机器人的思考都走同一条路：

```
BotAIStartFrame (引擎每帧发消息驱动)
  └─ for (i = 0; i < MAX_CLIENTS; i++)
         BotAdaptiveApply(bot_states[i]);   // M5 写回有效 skill
         BotActions(bot_states[i], ...);    // 所有 bot 同一个函数
```

`ai_*.c`（84 个文件）里**没有任何按机器人名字或角色分支的代码** —— 实测
`grep -rn "zzqBOT|zzqbot|sarge|xaero" --include=*.c` 在 AI 源码里零命中。

所以"谁更聪明"完全由 `bot_state_t` 里的两个来源决定：

| 来源 | 内容 | 由谁决定 |
|---|---|---|
| `bs->settings.skill` | 1–5 的难度档，**是行为等级，不只是准度** | 你加 bot 时选的档位 |
| `bs->character` | 性格与瞄准参数（角色文件） | `.bot` 文件里的 `aifile` 指向的 `xxx_c.c` |

## 二、skill 不只是"准不准"，它是能力开关

同样一段代码，按 skill 值**开或关某些能力**：

| 条件 | 位置 | 效果 |
|---|---|---|
| `skill < 3` | `ai_move.c:917` | 不会闪避 |
| `skill < 3` | `ai_move.c:966` | 不会 strafe jump 连跳 |
| `skill <= 2` | `ai_scan.c:761` | 完全不躲导弹 |
| `skill <= 3` / `<= 4` | `ai_scan.c:765,767` | 对导弹的察觉时间阈值（越高越早发现） |
| `skill <= 1` | `ai_self.c:280` | 完全不追踪敌人血量 |
| `skill >= 4` | `ai_self.c:286` | **直接读到敌人真实血量**（注释原文：*"It's Almost Like They Cheat!(tm)"*） |
| 全部 | `ai_aware.c:49` | 同时能盯住的目标数 = `MAX_AWARE_ENTITIES - 5 + skill` |
| 全部 | `ai_pickup.c:388` | 能提前计时的物品数 = `floor(skill) - 2` |
| 全部 | `ai_self.c:657` | 反应时间（`REACTIONTIME` 特征 → `bot_reaction_min..max`） |
| 全部 | `ai_action.c:359`、`ai_chat.c:32` | 重生随机量、打字速度 |

**所以 skill 1 和 skill 5 的 bot 不是"同一台机器调了精度"，是能力集不一样。**
一个 skill 5 的 bot 会躲导弹、会连跳、还"透视"你的血量；skill 2 的 bot 这三样都不会。

## 五、但 zzqAI 的 M5 会主动把差距拉平（默认开）

`ai_adaptive.c`：

```
每 bot_adaptive_interval（默认 6.0 秒）评估一次：
    peer  = 同场其他人（含真人）的平均分
    err   = (peer - score) / (|peer| + |score| + 1)     落后为正、领先为负
    target= err * bot_adaptive_range        （默认 ±1.5）
    偏移 每周期最多移动 bot_adaptive_rate     （默认 0.30，平滑防止跳变）
    有效 skill = 原始 skill + 偏移，裁剪到 [bot_adaptive_min, bot_adaptive_max]（1.0 ~ 5.0）
每帧把有效 skill 写回 bs->settings.skill（对所有读取 skill 的代码零侵入）
```

含义：**打得好的 bot 会被调弱，打得差的会被调强**，最终大家被拉到"和同场平均水平
差不多"。所以"zzqBOT 更聪明"这个差距在打几局之后会被系统主动抹掉。

想保留实力差距：`set bot_adaptive 0`（注意是 `CVAR_CHEAT`，要先开 cheats 或改默认值）。

## 六、实跑发现的一个细节：技能档位怎么选

角色文件（zzqBOT 和原版 bot 一样）**只写了 `skill 1` / `skill 4` / `skill 5` 三档**。

用 quake3e 专用服务器实测（`+addbot zzqBOT <档>`，看 `qconsole.log`）：

| 你选的档 | 引擎实际载入的角色档 |
|---|---|
| 1 | skill 1 |
| 2 | **skill 1 + skill 4**（两档都载，按两档插值） |
| 3 | **skill 1 + skill 4**（同上） |
| 4 | skill 4 |
| 5 | skill 5 |

原始日志（`addbot zzqBOT 2`，单只 bot）：

```
loaded skill 1 from bots/default_c.c
loaded skill 1 from bots/zzqbot_c.c
loaded skill 4 from bots/default_c.c
loaded skill 4 from bots/zzqbot_c.c
```

`default_c.c` 是每次载入角色时顺带取的默认值，所以"一对"= 一次角色载入；
上面是**两次载入**（skill 1 与 skill 4）⇒ 请求 2 或 3 时引擎取夹住该值的两个档位。

补充：brainworks 还有一层手工补偿（`ai_self.c:621`，原注释写的是"skill 1-3 特性相同"）：

```c
if (bs->settings.skill <= 1)      { acc *= 0.30; skill *= 0.30; }
else if (bs->settings.skill <= 2) { acc *= 0.60; skill *= 0.60; }
```

所以低档位之间的差距不只是插值，还被这层缩放进一步拉开。

## 七、一句话操作建议

| 想要的效果 | 怎么做 |
|---|---|
| zzqBOT 发挥全部实力 | `addbot zzqBOT 5`（或菜单里选 5） |
| 让 zzqBOT 和原版 bot 打，看实力差距 | `set bot_adaptive 0` 先关掉自适应 |
| 想长期保持"大家水平接近" | 保持 `bot_adaptive 1`（默认） |
| 只加原版 bot 陪练 | `addbot xaero 4` 等，参数同表可查 |
